# TechFest 2026 — React + Node + MongoDB

This frontend is paired with the `backend/` folder in this project.

## Run locally

1. Open a terminal in `frontend/` and run `npm install`.
2. Copy `.env.example` to `.env` and keep `VITE_API_URL=http://localhost:5000`.
3. Run `npm run dev`.
4. Open the Vite URL shown in the terminal, normally http://localhost:5173.

Start the backend separately first. See `../backend/README.md`.
